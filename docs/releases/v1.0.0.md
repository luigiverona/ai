# ai 1.0.0

The initial `ai` release provides a guided Arch Linux workstation setup through one
CLI. Complete and focused commands install declared Arch, AUR, and Flatpak software;
configure Git, GitHub, dedicated SSH access, two isolated Codex profiles, and shell
PATH; and verify the resulting readiness.

Setup inspects current state before mutation, renders a deterministic plan, requires
confirmation, performs full Arch upgrades, keeps AUR builds unprivileged, and preserves
existing SSH keys by default. Dry runs skip mutation, while `ai status` performs
complete read-only verification through the shared readiness implementation.

The bootstrap installs an immutable runtime archive without starting workstation setup.
Each release contains exactly the installer, archive, archive checksum, and checksum
manifest. Clean independent builds, archive validation, upload comparison, and build
provenance attestations protect the published release contract.
