# ai 2.1.0

Steam is now available in the `games` application category. It is installed per-user
from Flathub as `com.valvesoftware.Steam` through the existing Flatpak workflow.

`ai` does not configure multilib, GPU drivers, Steam accounts, Proton, or Flatpak
filesystem overrides. Existing fresh-install, collision, provenance, atomic update,
interruption-recovery, and verification safety boundaries remain unchanged.
