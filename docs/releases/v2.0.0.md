# ai 2.0.0

This breaking cleanup release narrows `ai` to its fresh-environment contract.

- Removed inventory and deletion of unrelated local and GitHub SSH keys. `ai` now manages
  only `~/.ssh/id_ed25519_ai_github`, its public companion, and its dedicated SSH
  configuration fragment; unrelated keys are ignored.
- Removed the redundant archive-specific `.sha256` sidecar. Releases now contain exactly
  `install`, `ai-<version>.tar.gz`, and `SHA256SUMS`.
- Removed the unused catalog-root environment override and production installer test hooks.
- Preserved strict collision refusal, verified provenance, atomic official-release updates,
  current-transaction interruption recovery, and readiness verification.
