# ai 2.2.0

`ai` is now explicitly maintained as a personal setup tool for fresh Arch Linux x86-64
workstations. Other distributions and customized installation environments are
unsupported. The proposed multi-distribution scope was rejected and is not part of the
runtime, validation, documentation, or support contract.

This release cleans up internal wording, maintainer documentation, version-bound tests,
and Arch-only validation. The application catalog is unchanged. Existing safety,
transaction recovery, source provenance, dry-run and status behavior, reproducible
three-asset releases, and release attestations remain intact.
